# SolarCRM

A full-stack CRM built for solar companies to manage leads, proposals, payroll, and team training — with role-based access for Admins, Managers, Sales Leads, Agents, HR, and Accountants.

🔗 Live Demo: https://crm-dashboard-client.vercel.app
📦 Backend Repo: https://github.com/ZAHIDHOSEN/CRM-Dashboard-Server

## Features

- JWT authentication with httpOnly cookies
- 6 role-based access levels (Admin, Leader, Closer, Setter, Installer,Client)
- Lead & proposal pipeline management
- Payroll and commission tracking
- Training modules 
- Audit logging
- Demo login for quick recruiter access

## Tech Stack

**Frontend:** React, TypeScript, Redux Toolkit, RTK Query, Tailwind CSS
**Backend:** Node.js, Express, MongoDB
**Deployment:** Vercel

## Getting Started

```bash
git clone https://github.com/ZAHIDHOSEN/CRM-Dashboard-Client
cd solarcrm
npm install
npm run dev
```

Create a `.env` file:

```
VITE_API_BASE_URL=https://crm-dashboard-server.vercel.app
```
